## 2. Призначення
- Предметна область: Запахи коду (М. Фаулер)
- Зв'язок із кваліфікаційною роботою: Програмний застосунок соціальна книжкова платформа, розробка
- Що робить агент: Агент роз'яснює 7 різновидів code smells, спираючись виключно на верифіковану локальну базу даних. У manual-agent реалізовано контрольований цикл операцій із трасуванням і перевіркою рішень, тоді як adk-agent активує інструменти через механізм Google ADK function-calling. За умови запиту до невідомих code smells система видає передбачувану відповідь про брак інформації, повністю виключаючи генерацію вигаданих фактів.
- Типові запити користувача: "Порівняй Long Method і Duplicated Code", "Що таке data clumps?", "Опиши code smell Object-Orientation Abusers"
- Чого агент не робить (межі): не виконує веб-пошук для неіснуючих в базі code smells; не вигадує дані поза локальним середовищем.
 
## 3. Архітектура
| Дія | Аргументи | Детермінована | Змінює середовище |
|---|---|---|---|
| `lookup_code_smell` | name | Так | Ні |
| `finish` | answer | - | Ні |

- Умови зупинки: finish; MAX_STEPS = 8
- Обробка відмов: невідомий code smell (агент повідомляє про відсутність підтверджених даних і не вигадує інформацію), некоректні аргументи (агент просить уточнити назву або опис code smell), досягнення ліміту кроків (агент завершує виконання без подальших викликів інструментів).
